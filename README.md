# 三重大学B試験対策 SPI問題集

スマートフォンから1セット10問の練習ができます。学習履歴と累計正答率は回答ごとに、このサイトを開いたブラウザに保存します。

## GitHubで問題を追加する

1. `sets.js` を開いて鉛筆アイコンで編集します。
2. 既存セットのオブジェクトを複製し、配列の最後にカンマで区切って追加します。
3. `id` を未使用の値（例 `verbal-02`）にし、`category` に「言語」「非言語」「模擬試験」のいずれか、`title` に表示名を書きます。
4. `questions` に10問を入れます。各問の `topic` は出題分野、`prompt` は問題文、`choices` はA〜E順の選択肢5個、`answer` は正答の半角英大文字1字、`explanation` は解説です。
5. **Commit changes** で main に保存します。Pagesの更新後、該当分野に表示されます。

初回の言語問題は「SPI基礎力チェック」問題編・解答解説編の問1〜10を収録しています。
